# SLY Company

> Projeto de desenvolvimento web para uma marca conceitual de streetwear, com identidade visual minimalista, urbana e contemporânea.

## 📌 Sobre o projeto

A **SLY Company** é um projeto de desenvolvimento web criado para representar uma marca conceitual de streetwear através de uma experiência digital moderna e responsiva.

O projeto foi desenvolvido com foco tanto na construção da interface quanto na aplicação prática de conceitos de **HTML, CSS e JavaScript**, incluindo manipulação do DOM, eventos, componentes dinâmicos e armazenamento de dados no navegador.

A identidade visual do projeto foi construída para transmitir uma estética minimalista e urbana, utilizando imagens, tipografia e composição visual como parte da experiência da marca.

---

## 🎯 Objetivos

- Desenvolver um site completo para uma marca conceitual.
- Praticar desenvolvimento de interfaces utilizando HTML e CSS.
- Aplicar JavaScript para criar interações e funcionalidades.
- Trabalhar com manipulação do DOM.
- Implementar um catálogo de produtos dinâmico.
- Criar um carrinho de compras utilizando `LocalStorage`.
- Desenvolver uma interface responsiva.
- Praticar organização de arquivos e estrutura de projeto.
- Utilizar Git e GitHub para versionamento e publicação do projeto.

---

## ✨ Funcionalidades

### 🏠 Página inicial

- Hero Section com imagem de destaque.
- Apresentação da Collection 001 — Roots.
- Chamada para exploração da coleção.

### 👕 Coleção

- Catálogo de produtos.
- Cards de produtos gerados dinamicamente com JavaScript.
- Filtro por categoria.
- Exibição de imagens frontais e traseiras.
- Informações de nome, preço e descrição.

### 🔎 Visualização de produtos

- Modal com informações detalhadas do produto.
- Visualização do produto.
- Descrição e preço.
- Adição de produtos ao carrinho.

### 🛒 Carrinho

- Adição e remoção de produtos.
- Controle de quantidade.
- Cálculo do total.
- Persistência dos produtos utilizando `LocalStorage`.

### 📖 About

Página dedicada à apresentação e conceito da SLY Company.

### 📩 Contact

- Formulário de contato.
- Validação dos campos.
- Interface dedicada para contato com a marca.

### 📱 Responsividade

O projeto utiliza uma estrutura responsiva para adaptar a interface a diferentes tamanhos de tela.
